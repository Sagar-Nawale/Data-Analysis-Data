# IPL Data Analysis

## Project Overview

This project analyzes Indian Premier League (IPL) match data using Python and data analysis libraries.

## Objective

The main objective is to analyze IPL match data and understand team performance, match results, toss decisions, and scoring patterns.

## Tools and Technologies

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Key Analysis

* Team-wise match wins and losses
* Season-wise team performance
* Toss winner and match winner analysis
* Team runs analysis
* Match result analysis

## Project File

`IPL Project (python).ipynb`

## Conclusion

This project helps identify useful patterns in IPL match data through data analysis and visualization.
